# 学 Китайские карточки — Telegram Mini App

Карточки китайских слов для учеников: свайп вправо — «знаю», влево — «не знаю» (покажет пиньинь, перевод, пример и как писать иероглиф). Незнакомые слова возвращаются в конец колоды. В конце — тест: предложение с пропуском и варианты из карточек. Итоговый отчёт ученик отправляет учителю одной кнопкой.

Полностью бесплатно: хостинг — GitHub Pages, озвучка генерируется GitHub Actions. Сервер и токен бота не нужны.

## Возможности

- свайпы и кнопки «Знаю / Не знаю», тактильный отклик в Telegram
- пиньинь раскрашен по тонам: 1 — красный, 2 — зелёный, 3 — синий, 4 — фиолетовый, лёгкий — серый
- озвучка слов и предложений (mp3, работает и на Android, и на iPhone)
- анимация порядка черт иероглифа ([Hanzi Writer](https://hanziwriter.org))
- «не знаю» → карточка вернётся позже (до 3 раз)
- тест по выученным словам, отчёт с ошибками
- «📤 Отправить учителю» — готовый текст отчёта в чат учителя
- подстраивается под светлую/тёмную тему Telegram

## Подключить к боту

1. В [@BotFather](https://t.me/BotFather): `/newbot` → создать бота.
2. `/newapp` → выбрать бота → название, описание, картинка 640×360 → **Web App URL**:
   `https://sharifzoda4156-ops.github.io/chinese-cards/`
   → короткое имя, например `cards`.
3. Ссылка для учеников: `https://t.me/ИМЯ_БОТА/cards`.
4. (по желанию) `/mybots` → бот → Bot Settings → Menu Button → тот же URL — кнопка появится прямо в чате бота.

## Разделы и уроки

При обычном входе: **Старт → HSK-3 → Уроки 1–18 → Начать урок**.
Доступны уроки 1–5 из блоков 生词 учебника 新HSK教程 3 — всего 135 карточек.

| Урок | Слов | Печатные страницы блоков 生词 |
|---|---:|---|
| 1 | 27 | 2, 4, 6, 8 |
| 2 | 28 | 11, 13, 15, 16 |
| 3 | 26 | 20, 22, 23, 25 |
| 4 | 27 | 30, 32, 33, 35 |
| 5 | 27 | 39, 41, 42, 44 |

Имена собственные в колоды не входят.
Переводы на русский и примеры для карточек и теста подготовлены отдельно.
Демонстрационные 10 слов заменены. Уроки 6–18 видны с отметкой «Скоро» и недоступны.

Каталог разделов и уроков — `decks/catalog.json`. Данные урока — `decks/lesson1.json`.
Чтобы добавить следующий урок:

1. Создайте `decks/lesson6.json` с полями `title`, `subtitle` и непустым массивом `words`.
2. Для каждого слова заполните `id`, `hanzi`, `pinyin`, `ru`, `sentence`, `sentencePinyin`, `sentenceRu`.
   `id` — уникальный идентификатор латиницей (`a-z`, цифры, `_`, `-`).
   Пиньинь слова пишется по слогам через пробел со знаками тонов.
   Для многозначного чтения можно указать `audioText` с однозначным словом-примером
   и `audioNote` с пояснением ученику (например, 长 → 长大, zhǎng dà).
   В `sentence` должен быть ровно один пропуск `___`, а пиньинь и перевод описывают полное предложение.
   Среди предложенных вариантов должен быть только один подходящий ответ.
   Если в уроке есть синонимы, укажите их `id` в `quizExcludes` у соответствующего слова;
   они не появятся в качестве неправильных ответов на этот вопрос.
   Например, 拍照 и 照相 исключаются друг для друга. Для пояснения используется `note`.
3. В записи урока в каталоге поставьте `available: true`, заполните `subtitle` и `wordCount`.
4. Проверьте данные и интерфейс командами из раздела ниже, затем сохраните изменения в `main`.

GitHub Actions создаст MP3 слова и полного предложения для каждой карточки и опубликует сайт.
Кэш озвучки проверяет текст, голос и скорость: изменённые записи генерируются заново.

Прямая ссылка на первый урок:
`https://sharifzoda4156-ops.github.io/chinese-cards/?deck=lesson1`.
В Telegram поддерживается `startapp=lesson1`. Без параметра показывается главный экран.
Для нового урока используйте его идентификатор вместо `lesson1`.
Отчёт содержит ссылку на конкретный урок; отправку и выбор чата подтверждает ученик.
Прогресс между открытиями не сохраняется.

## Проверка

```bash
npm install --no-save playwright@1.62.1
npx playwright install chromium
node --check app.js
node tests/app.test.cjs  # нужен установленный playwright и Chromium
python3 tests/audio_test.py
```

## Запуск локально

```bash
python3 -m http.server 8000      # открыть http://localhost:8000
pip install edge-tts && python scripts/gen_audio.py   # озвучка локально (по желанию)
```
